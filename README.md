# 日本株 出来高急増スクリーナー(GitHub Actions版)

出来高が急増した銘柄を抽出し、**GitHub Pagesに掲載**しつつ**Googleスプレッドシートに追記**します。
さらに、過去に検出した銘柄の**1ヶ月後の株価**を自動で追記していくため、
「検出した銘柄がその後どうなったか」を後から検証できます。

| スクリプト | 内容 | 出力 |
|---|---|---|
| `screener.py` | 引け後。当日出来高が7日平均の**2倍以上** | `output/eod.html` / シート区分「引け後急増」 |
| `screener_ama.py` | 前場(9:00-11:30)。前場出来高が7日平均の**1.5倍以上**、および上放れ並び赤パターン | `output/ama.html` / シート区分「前場急増」「上放れ並び赤」 |

抽出条件:

- 出来高倍率がしきい値以上
- 過去7営業日の平均売買代金 ≥ 10億円/日(閑散銘柄の除外)
- 過去7営業日に出来高ゼロの日がある銘柄は除外
- 祝日など休場日は自動スキップ

## スプレッドシートの構成

`tracking` シートに1検出=1行で追記されます(存在しなければ自動作成)。

| 検出日 | 区分 | コード | 銘柄名 | 市場 | 検出時株価 | 出来高倍率 | 1ヶ月後日付 | 1ヶ月後株価 | 1ヶ月騰落% |
|---|---|---|---|---|---|---|---|---|---|
| 2026-09-01 | 引け後急増 | 7203 | トヨタ | プライム（内国株式） | 2850.0 | 3.21 | | | |
| 2026-07-01 | 上放れ並び赤 | 6758 | ソニーG | プライム（内国株式） | 3000.0 | 2.10 | 2026-07-31 | 3787.0 | 26.23 |

- 右3列は空欄で追記され、**検出から30日(暦日)が経過した後の実行時**に自動で埋まります
  (30日後が休場日なら、その次の営業日の終値を採用)
- 同じ日・同じ区分・同じ銘柄は二重に追記されないため、同日に複数回実行しても安全です
- 同じ銘柄が別の区分で検出された場合は、区分ごとに別行になります(区分別の成績比較用)

## セットアップ手順

### 1. Googleサービスアカウントの作成

1. https://console.cloud.google.com/ でプロジェクトを作成(既存でも可)
2. **APIとサービス → ライブラリ** で `Google Sheets API` を検索して**有効化**
3. **APIとサービス → 認証情報 → 認証情報を作成 → サービスアカウント** を選択し、
   適当な名前(例: `screener`)で作成(ロールの付与は不要)
4. 作成したサービスアカウントを開き、**キー → 鍵を追加 → 新しい鍵を作成 → JSON**
5. ダウンロードされたJSONファイルの**中身をすべて**控える

### 2. スプレッドシートの準備

1. Googleスプレッドシートを新規作成
2. 右上の**共有**から、手順1のサービスアカウントのメールアドレス
   (`...@....iam.gserviceaccount.com`。JSONの `client_email` に書かれています)を
   **編集者**として追加
3. URLからシートIDを控える
   `https://docs.google.com/spreadsheets/d/【ここがシートID】/edit`

### 3. Secretsの登録

リポジトリの **Settings → Secrets and variables → Actions → New repository secret** で2つ登録:

| Name | Value |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_JSON` | 手順1でダウンロードしたJSONの中身をそのまま貼り付け |
| `SPREADSHEET_ID` | 手順2で控えたシートID |

### 4. 動作テスト

**Actions タブ → 対象のワークフロー → Run workflow** で手動実行できます。
シートに行が追記されれば成功です。

> Secretsが未設定の場合、スプレッドシートへの書き込みはスキップされますが、
> スクリーニング自体とGitHub Pagesへの掲載は通常どおり動作します。

## カスタマイズ

`screener.py` / `screener_ama.py` 冒頭の設定を編集:

- `RATIO_THRESHOLD` : 出来高倍率のしきい値(引け後 2.0 / 前場 1.5)
- `MIN_AVG_VALUE` : 平均売買代金の下限(既定 10億円)

`sheets.py` 冒頭の設定を編集:

- `FOLLOWUP_DAYS` : 何日後(暦日)の株価を追跡するか(既定 30)
- `WORKSHEET_NAME` : 書き込み先のシート名(既定 `tracking`)

実行時刻を変えるには `.github/workflows/*.yml` の cron を編集
(UTC指定。JST−9時間。例: 18:00 JST → `0 9 * * 1-5`)

## 注意事項

- Yahoo Financeの非公式データを利用しているため、仕様変更で動かなくなる可能性があります
- データ反映は大引け後30分〜1時間程度かかるため、引け後の実行時刻は16:30 JST以降を推奨
- 追跡株価は**未調整終値**です。追跡期間中に株式分割・併合があった銘柄は騰落%が実態とずれます
- 60日以上pushがないリポジトリはGitHubがスケジュール実行を自動停止します
  (メールで通知が来るので、その場合はActionsタブから再有効化してください)
